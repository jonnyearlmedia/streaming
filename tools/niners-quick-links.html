    How this actually works

    There is no permanent link to a single game. Movies and shows have IMDb ids, so stremio:///detail/movie/tt0111161 points at the same title forever. Live sports don't. Sports Streams builds an event item when the game shows up in its catalog, usually the day of, and that id dies with the event. So a link made in September for a December game would point at nothing.

    What's stable is the catalog. Every button here opens stremio:///discover/{your addon}/sport/sports_american_football, which is the American Football list. On game day the Niners feed is sitting right there, a tap away. After kickoff the board flips a game to Live; a day after, the button switches to the Recaps catalog.

    Playback: a deep link lands on a page, never straight into a stream. Stremio's ?autoPlay=true flag only works on detail links with a real id, which live events don't have. You still pick the feed. Whether it plays in Stremio or hands off to an external player is your player setting inside Stremio, not something a link can force.

    If a button does nothing: custom stremio:// links are blocked inside some embedded viewers. Hit Copy, paste in your browser bar, done. On the phone, add this board to your home screen so it's one icon.
